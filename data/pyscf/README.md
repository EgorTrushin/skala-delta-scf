# Supplied PySCF results

`../csv/pyscf_excitations.csv` supplies 255 molecular result rows at aug-cc-pVTZ:
120 QUEST1 rows, 80 ST-gap rows, and 55 QUEST6 rows. PBE, r2SCAN and PBE0 each
have one variant; Skala has radii-on and radii-off variants. Dataset/molecule
identifiers match the CP2K CSV. `radii_adjust=not_applicable` means that the
Skala on/off comparison does not apply to that row; it does not claim that
conventional functionals disable PySCF's normal grid partitioning.

The exported values come from the reviewed calculation records used for the
manuscript comparison. UKS singlets use `2 E(mixed) - E(triplet)`; ROKS uses the
optimized singlet total and a separately optimized restricted triplet. Excitation
energies subtract the ground-state energy. Conversion uses 27.211396132 eV/Ha,
the same as the CP2K export. QUEST6 contains only the benchmarked singlet values.
CSV values are supplied inputs to the public analysis, not regenerated by the
CP2K parser. Regenerate the comparison with:

```bash
uv run python scripts/table_codes.py
```

## Recorded implementation and settings

The calculation metadata record Python 3.12.14, PySCF 2.14.0, LibXC 7.0.0,
and (for Skala) package 2026.9 with checkpoint `skala-1.1-rev1`. Runs use
aug-cc-pVTZ, density fitting with aug-cc-pV5Z-RIFIT, and grid level 3.
The Skala checkpoint SHA256 is
`7f3e8622e1eb520ccd88a55464c3e359ac4d7e5ccbd1fb77a26afa1e1c20a5cd`.
`provenance.json` preserves the recorded run parameters, software/model versions,
per-system overrides, reviewed source hashes, and original output-file hashes.

Calculations used the separate `delta-scf-skala` codebase, including a custom
ROKS implementation. That implementation is not supplied here. This repository
reproduces analysis of the supplied PySCF results, not the PySCF calculations
from scratch; the analysis environment need not install PySCF or Skala.

## Interpretation

These are comparisons of the archived computational protocols, not uniformly
controlled changes of a single grid setting. Recorded radii-on/off differences
also include UKS solver settings for QUEST1 thioformaldehyde, a mixed-state
convergence threshold for ST-gap Molecule4, and ground/UKS settings for QUEST6
dimethylaniline. Twisted PP also differs in its initial promotion. Exact
recorded differences are retained in `provenance.json`. Improved agreement
must not be attributed solely to radii adjustment in these cases.
Numerical convergence and energy agreement do not establish spectroscopic
state assignment. The previously unresolved twisted-PP/PBE0 mixed/triplet
orbital correspondence is not resolved by this CSV export.

## Original calculation records

Original PySCF JSON/output files are retained in the development archive and
are not included in this submission repository. The supplied CSV and recorded
provenance are sufficient to reproduce the numerical comparison. The
`raw_files` entries in `provenance.json` identify the original records by their
archive-relative paths and SHA256 hashes; they are not local repository paths.
